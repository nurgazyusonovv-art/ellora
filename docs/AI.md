# AI жана тарифтер — план

Негизги эреже: **окуучу эч качан төлөбөйт. AI'нын чыгымын мугалимдин тарифи (же платформа) көтөрөт.**
Мугалимге AI убакыт үнөмдөйт (сабак даярдоо, текшерүү) — ошол үчүн төлөйт. Окуучуга AI жардамчы
мугалимдин классынын «бонусу» катары келет.

## 1. Тарифтер

| | Free (мугалим) | Pro (мугалим) | Мектеп (кийин) |
| --- | --- | --- | --- |
| Баасы | 0 | ~300–500 сом/ай (пилотто текшерилет) | келишим боюнча, мугалимдердин саны менен |
| Учурдагы бардык функциялар | ✅ | ✅ | ✅ |
| AI менен сабак түзүү | айына 2 (сынап көрүү) | айына 40 | Pro × мугалимдер |
| AI менен блок/суроо түзүү | айына 10 | чексиз дээрлик (адилет лимит) | Pro × мугалимдер |
| Ачык жоопторду AI баалоо + класс кыскачасы | — | ✅ | ✅ |
| Окуучулардын AI-жардамчысы | ар бир окуучуга күнүнө 5 кеңеш | күнүнө 30 кеңеш | Pro менен бирдей |

- Окуучуда «тариф» деген түшүнүк жок. Анын лимити **ал кирген класстын мугалиминин тарифинен** алынат
  (бир нече класста болсо — эң жогорусу).
- Free'деги кичинекей лимиттер — мугалим AI'ны көрүп, баалуулугун сезиши үчүн. Чыгымын платформа көтөрөт.
- Сандар башталгыч болжол: пилотто чыныгы колдонуу (`ai_usage`) боюнча тууралайбыз.

## 2. AI функциялары

### Мугалим (Pro)

1. **Сабакты AI менен түзүү.** КТП'ден тема + класс + узактык → AI 5 бөлүктүү сабактын JSON долбоорун жазат
   (`LESSON_FORMAT.md` боюнча). Сервер аны `lesson-types.ts`/`lesson-edit.ts` текшерүүсүнөн өткөрөт, бузулган
   болсо 1 жолу оңдотот. Натыйжа **draft** болуп конструкторго ачылат — мугалим карап, түзөтүп, анан жарыялайт.
2. **Блок түзүү конструктордун ичинде.** «Дагы 3 тест суроосу», «Ушул темага code_task + тесттер»,
   «Жөнөкөйлөт / 5-класс үчүн кыл». Ар бир code_task'тын тесттери Pyodide менен текшерилет (эталон чечим өтүшү керек).
3. **Ачык жоопторду баалоо жана класс кыскачасы.** Натыйжалар барагында: `open` жоопторду топторго бөлүү
   («5 окуучу циклди шарт менен чаташтырды»), ар бирине сунушталган баа. Баа **сунуш гана** — мугалим ырастайт.

### Окуучу (акысыз)

4. **AI-жардамчы «Түшүнбөдүм» баскычы** — Learning, Practice жана Бышыктоо бөлүктөрүндө гана:
   - `code_task`: катаны жана тест эмнеге өтпөгөнүн түшүндүрөт, **туура кодду жазбайт**.
   - `mcq`/`parsons`/`bug_hunt`: туура эмес жооптон кийин багыт берет, туура вариантты айтпайт.
   - Кеңеш тепкичи: 1-кеңеш жалпы → 2-кеңеш тагыраак → 3-кеңеш кайсы сапка карап көр. Андан ары — «мугалимден сура».
   - **Exit ticket'те AI өчүк** (бул баалоо).
   - Эркин чат жок: окуучу AI'га каалаганын жаза албайт, AI ар дайым учурдагы блокко байланган. Бул чыгымды да,
     балдардын коопсуздугун да чектейт.
   - Мугалим классы же тапшырма боюнча AI'ны өчүрө алат.

## 3. Архитектура

```
src/lib/ai/
  client.ts      Claude API (server-only, ANTHROPIC_API_KEY — Vercel env'де гана)
  prompts.ts     системалык prompt'тор (кыргызча жооп, жоопту ачпа, 5 бөлүктүн эрежелери)
  quota.ts       лимитти текшерүү + ai_usage'ке жазуу
  plans.ts       тарифтин лимиттери (бирдиктүү булак)
src/app/actions/ai.ts   Server Actions: generateLesson, generateBlocks, studentHint, summarizeOpenAnswers
```

- **Модель:** окуучунун кеңештери — арзан жана тез модель (Claude Haiku 4.5); сабак түзүү жана баалоо — күчтүүрөөк
  (Claude Sonnet 5.5). Баалар өзгөрөт — тарифти эсептөөдөн мурун текшериңиз.
- **Сабак JSON'у** structured output / tool аркылуу алынат, андан кийин биздин TypeScript текшерүүсү.
- **Ар бир чакыруу:** 1) `requireRole`, 2) `quota.ts` — лимит калдыбы, 3) AI, 4) `ai_usage`ке токендер жазылат.
  Лимит бүтсө: `{ error: "Бүгүнкү AI кеңештер бүттү. Мугалимиңизден сураңыз." }`.
- **Жоопту ачпоо:** туура жоопту AI серверде көрөт (`student-view.ts` браузерге жибербейт), бирок prompt'то
  «айтпа» деп жазылат жана жооп кайтарылаардан мурун текшерилет: туура вариант / тесттин `expected` / эталон
  коду тексте бар болсо — жооп кайра жазылат же жалпы кеңеш берилет.
- **Жеке маалымат:** AI'га окуучунун аты-жөнү, логини жөнөтүлбөйт — блок, анын коду жана ката гана.
- **Чыгымды коргоо:** кирүү текстинин узундугу чектелет, бир блокко 3 кеңеш, кайталанган суроо кэштелет
  (бир блок + бир ката = бир жооп), prompt caching системалык prompt үчүн.

## 4. Маалымат базасы (`0008_ai.sql`)

| Таблица / талаа | Эмне | RLS |
| --- | --- | --- |
| `subscriptions` (teacher_id, plan `free`/`pro`/`school`, status, period_end, source `manual`/`payment`) | Мугалимдин тарифи | мугалим өзүнүкүн окуйт; жазуу — сервер (service role) гана |
| `ai_usage` (user_id, class_id, kind, model, input_tokens, output_tokens, created_at) | Ар бир AI чакыруу | колдонуучу өзүнүкүн; мугалим өз класстарынын окуучуларыныкын; insert — сервер гана |
| `classes.ai_enabled` (boolean, default true) | Класста окуучунун AI'сы | мугалимдин учурдагы саясаты |
| `payments` (кийин) | Төлөмдөрдүн тарыхы | мугалим өзүнүкүн; жазуу — webhook (сервер) |

Лимитти эсептөө: SQL функция `ai_quota_left(user_id, kind)` — ушул күн/айдагы `ai_usage` саны vs `plans.ts`тагы лимит.

## 5. Төлөм

Кыргызстанда Stripe иштебейт, ошондуктан эки кадам:

1. **Пилот — кол менен.** Мугалим MBank/Optima QR же которуу менен төлөйт → админ `/admin/teachers`те «Pro'го өткөр
   (30 күн)» баскычын басат → `subscriptions` жаңыланат. Код аз, тобокелдик жок.
2. **Өсүү — автоматтык.** Жергиликтүү провайдер (Finik, Freedom Pay/PayBox, O!Деньги, ELQR — шарттарын салыштырып
   тандайбыз) → `/api/payments/webhook` кол тамганы текшерип, `payments` жана `subscriptions`ти жаңылайт.
   Мөөнөт бүтөрдөн 3 күн мурун эскертүү.

Мектеп лицензиясы — келишим + эсеп-фактура, админ кол менен ачат.

## 6. Тобокелдиктер

| Тобокелдик | Эмне кылабыз |
| --- | --- |
| Окуучулар AI'га көз каранды болуп, өзү ойлобой калат | Кеңеш тепкичи, жооп эч качан берилбейт, Exit ticket'те AI жок, мугалим өчүрө алат |
| AI ката же туура эмес кыргызча жазат | Мугалимге баары draft/сунуш болуп келет; окуучу «Кеңеш пайдасыз болду» деп белгилей алат |
| Чыгым көзөмөлсүз өсөт | Катуу лимиттер, `ai_usage` админ панелде, айлык жалпы бюджет чеги (ашса Free AI убактылуу өчөт) |
| Төлөм провайдери кечигет | Кол менен активдештирүү иштей берет |
