# Колдонуу жана Баалоо: изилдөөгө таянган өнүктүрүү планы

2026-10-25. Бул изилдөө жана сунушталган иш кезеги. Төмөнкү жаңы блоктор ишке ашырылган же деплой болгон деп эсептелбейт. Өлкөнүн ыкмасынын болушу анын натыйжалуулугун өзүнчө далилдебейт; Ellora үчүн жыйынтыктар — булактарга таянган долбоордук сунуштар.

## Негиз жана булактар

- Финляндиянын улуттук программасы: предметтик максаттарга таянган, ар түрдүү жана окууну колдогон баалоо; предметтер аралык модулдар. Ellora үчүн: бир гана тесттен эмес, иштин продуктусунан жана түшүндүрмөдөн далил алуу. [EDUFI](https://www.oph.fi/en/education-and-qualifications/national-core-curriculum-primary-and-lower-secondary-basic-education)
- Эстония: төмөн тобокелдүү баалоо окуучуга/мугалимге окууну жакшыртуу үчүн маалымат берет. Бул барак стратегиялык багыттын сүрөттөлүшү, эксперименттик таасир баалоосу эмес. Ellora үчүн: катаны жазалоодон мурда анын себебин ачкан тапшырма. [Education Estonia](https://www.educationestonia.org/innovation/assessment/)
- Сингапур SLS: даярдыкка жараша материал/тапшырма/пикир сунуштоо, түшүнүктөр боюнча мугалим панели, суроо аркылуу жетектөөчү ЖИ. ALS азыр бардык предметти камтыбайт; бизге информатика үчүн ушундай механизмди долбоорлоо сунушталат. [MOE SLS, 24 July 2026](https://www.learning.moe.edu.sg/teachers/teaching-and-learning-on-sls/aied-features/)
- SLS оюн окуяларын жана шарттарга байланышкан жетишкендиктерди колдойт. Ellora үчүн: максатка байланышкан кыска окуя/миссия. [SLS Game Stories, 23 July 2026](https://www.learning.moe.edu.sg/teachers/teacher-user-guide/gamify/game-stories-and-collectibles/)
- Англиянын EEF далилдер топтому: тапшырма/максатка байланышкан, эмнени жакшыртуу керектигин так айткан пикир. ЖИнин ар бир пикири ушундай таасир берет деген тыянак чыгарылбайт. [EEF Feedback](https://educationendowmentfoundation.org.uk/education-evidence/teaching-learning-toolkit/feedback)
- Австралиянын AERO: аралык менен эстеп жооп берүү, башка кырдаалда кайра колдонуу жана жеткиликтүү татаалдык. [AERO](https://www.edresearch.edu.au/guides-resources/practice-guides/spacing-and-retrieval-practice-guide-full-publication)
- Оюндаштыруунун жыйынтыгы ар түрдүү; максатка байланышпаган оюн алаксытышы мүмкүн. [Australian Department of Education](https://www.education.gov.au/australian-curriculum/national-stem-education-resources-toolkit/i-want-know-about-stem-education/different-kinds-stem-education-initiatives/gamification)
- Санарип колдонуу өзүнөн-өзү жакшы жыйынтык кепилдиги эмес. PISA 2022деги байланыштар себеп-натыйжа далили катары кабыл алынбайт. [OECD](https://www.oecd.org/en/publications/pisa-2022-results-volume-ii_a97db61c-en/full-report/component-12.html)

## Азыр бар жана кошула турган нерсе

Бар: Python тапшырма/тест, Parsons, bug_hunt, ачык жооп/критерий, изилдөө, презентация, ЖИ жардамчы, монета, көндүм/сапат панели, кайра оңдоо, кайталоо, маршрут, топтук иш жана жалпы таймер. Алардын чыныгы класстагы айрым пилоттору ачык. Жаңы иш буларды кайталабай бириктирет.

Жаңы: жалпы дал келтирүү/категориялоо блогу, коддон тышкары кадам иреттөө, миссия агымы, өз алдынча жаңы практикалык далил, электрондук таблица чөйрөсү жана жардамдын колдонулушун далилге байланыштуу так көрсөтүү.

## Колдонуу бөлүгү

«Жаңы кырдаал → аракет → максаттуу пикир → оңдоо → башка мисал» агымы. Демейки 2–3 тапшырма жетиштүү; бардык оюнду ар сабакка кошуу талап кылынбайт.

| Түрү | Информатика мисалы | Эмне үйрөнгөнүн көрсөткөн далил |
| --- | --- | --- |
| Дал келтирүү жана негиздөө | Формула ↔ эсептөө максаты; түзмөк ↔ функция | Дал келтирүү + бир тандоонун себеби |
| Кадамдарды иреттөө | Файлды уюштуруу же алгоритм түзүү | Ирет + кийинки жаңы мисал; Python үчүн Parsons кайра колдонулат |
| Катаны таап оңдоо | if чек мааниси же формуланын туура эмес диапазону | Оңдолгон иш + эмне үчүн ката болгонун түшүндүрүү |
| Параметрди өзгөртүп сыноо | Шарт/циклдин жыйынтыгын алдын ала айтуу | Божомол, аткарылган сынак жана жыйынтык |
| Чыныгы чакан иш | Мектептик иш-чаранын бюджети | Таблица/формула/код + мугалим бекиткен критерий |
| Жуптук миссия | Бирөө чечет, экинчиси текшерет; ролдор алмашат | Жалпы иштен кийин ар окуучунун жеке жаңы мисалы |

## Баалоо бөлүгү

Кыска, окуучунун өз алдынча түшүнүгүн ачкан агым: 1) башка сандар/кырдаал менен чакан практикалык тапшырма; 2) «эмне үчүн?» суроосу; 3) ишеним/өзүн баалоо. Баштапкы ойду салыштыруу сакталат. 5 мүнөттүк бөлүккө тапшырмаларды баткыруу үчүн мугалим көлөмдү тандайт.

Машыгууда кеңеш/кайра аракет болот. Өз алдынча далил учурунда даяр жооп же ЖИ жардам берилбейт; кийин кайра үйрөнүү жана жаңы мисал өзүнчө аракет катары сакталат. Учурдагы Exit ticket жообу/бир аракет эрежеси жана баштапкы жооп өчүрүлүп кайра жазылбайт. Күтүүдөгү мугалим текшерүүсү «ката» эмес. Монета, ылдамдык, убакыт бүтүшү же экрандагы басуулардын саны өздөштүрүү катары эсептелбейт.

## Иш кезеги жана кабыл алуу

1. **Интерактивдүү блоктор:** дал келтирүү/категориялоо жана жалпы иреттөө. Мобилдик басуу/клавиатура жолу, 44px, түстөн тышкары белги. Сервердик детерминисттик текшерүү, катага түшүндүрмө, кайталанган сыйлыкка коргоо. Блоктордун азыркы ID/жооп тарыхы сакталат.
2. **Миссия жана жеке далил:** максат/окуя/2–3 иш/жаңы мисал. Мугалим оюнду өчүрө алат. Жалпы таймердин учурдагы бөлүгү сакталат; бүтпөгөн иш автоматтык нөл эмес. Кайра иштөө үчүн мугалим башка мүмкүнчүлүк ачат.
3. **Таблица чөйрөсү:** уяча/формула/диапазон/кайра эсептөө, SUM/AVERAGE, ишти сактоо/кайра ачуу. Формула eval/эркин JS аркылуу аткарылбайт. Альтернативдүү туура чечимдерге жана башка кириш маалыматка текшерүү; форматталган даяр санды гана жазуу формула көндүмү катары кабыл алынбайт. Андан кийин логикалык чынжыр жана HTML/CSS чөйрөлөрү өзүнчө долбоор.
4. **ЖИ/отчет менен бириктирүү:** ЖИ текшерилген блок форматын гана толтурат, мугалим бекитет. Көндүм панели биринчи аракетти, жардам менен аткарууну жана жаңы өз алдынча далилди бөлүп көрсөтөт; туруктуу «алсыз» энбелгиси жок. Бар маршрут/кайталоо/оңдоо агымдары кайра колдонулат.
5. **Бир тема боюнча пилот:** 2–4 сабак, бир класс. Мисалы Python if же таблица. Алдын ала жана кийинки окшош татаалдыктагы башка мисалдар; 7 күндөн кийин эстеп колдонуу; камтуу/жардам колдонуу/кайталанган ката/мугалим даярдоо убактысы. Бир класстагы өсүштөн платформа себеп болду деп тыянак чыгарылбайт. Кийинки кеңейтүүдө салыштырылуучу агым керек.

Кийинки функциялар: иш портфолиосу, критерий менен өз ара пикир, максат боюнча мугалим текшерген тапшырмалар банкы, ЖИ жообун далил менен текшерүү сабаттуулугу, байланыш начар болгондо ишти калыбына келтирүү. Биринчи кезекте жаңы оюндардын саны эмес, жаңы кырдаалда өз алдынча чечүүнүн сапаты бааланат.
