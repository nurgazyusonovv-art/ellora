## Түстөр

Токендер `src/app/globals.css` ичинде `@theme` блогунда. Tailwind'де `bg-accent`, `text-muted` деп колдонулат.

| Токен | Hex | Кайда |
| --- | --- | --- |
| `bg` | `#F2F5F3` | Беттин фону |
| `surface` | `#FFFFFF` | Карточкалар |
| `surface-2` | `#E8EEEB` | Прогресс тилкесинин фону, нейтралдуу чип |
| `ink` | `#15242A` | Негизги текст |
| `muted` | `#4F6267` | Кошумча текст |
| `line` | `#D5DEDA` | Чек аралар |
| `accent` | `#0C7563` | Негизги баскычтар, шилтемелер, прогресс |
| `accent-soft` | `#D5ECE6` | Тандалган абал, маалымат блоктору |
| `amber` / `amber-soft` | `#7A5405` / `#FBEFD2` | XP, «көңүл буруу» |
| `good` / `good-soft` | `#17683A` / `#DDF1E4` | Туура, «түшүндү» |
| `bad` / `bad-soft` | `#9E2F27` / `#F8E0DD` | Ката, «жардам керек» |
| `code` | `#0F2328` | Код блокторунун фону (эки темада тең караңгы) |
| `nav` | `#15242A` | Мугалимдин капталдагы менюсу |

Статус түстөрү (good/amber/bad) негизги accent'тен бөлөк — алар абалды гана билдирет.

## Шрифттер

| Роль | Шрифт | Колдонуу |
| --- | --- | --- |
| Display | Unbounded 500/700 | Беттин аталыштары, чоң сандар (`font-display`) |
| Body | Golos Text 400/500/600 | Бардык текст (кыргыз тамгалары ң, ө, ү толук бар) |
| Mono | JetBrains Mono | Код, класс коддору, XP, сандар колонкада (`font-mono`) |

Өлчөмдөр: аталыш 24–30px, бөлүм аталышы 18px, текст 15–16px, кошумча 13–14px, uppercase белги 12px + `tracking`.

## Компоненттер (`src/components/ui.tsx`)

- `Button` / `ButtonLink` — `primary` (accent), `secondary` (ак, чек арасы бар), `ghost`
- `Card` — ак фон, 1px `line` чек ара, 16px радиус
- `Chip` — абал белгиси: `good`, `warn`, `bad`, `accent`, `neutral`
- `Field` — label + input, ката үчүн `FormError`
- `Progress` — 8px бийиктиктеги тилке
- `RichText` — `**калың**` жана `` `код` `` колдоо

## Принциптер

- **Телефон биринчи:** окуучунун бардык беттери 375px'те текшерилет. Мугалимдин беттери компьютер үчүн, бирок
  телефондо да бузулбасын (капталдагы меню → астыңкы тилке).
- Баскычтардын бийиктиги ≥44px, фокус абалы көрүнүп турсун (`:focus-visible` accent түстө).
- Абалды түс менен гана эмес, текст менен да көрсөт (чиптин ичинде сөз бар).
- Эмодзи колдонбо; иконкалар — сызык SVG (stroke 2).
- Карточкаларга көлөкө жана градиент кошпо.
- Тексттер жөнөкөй кыргыз тилинде, окуучуга «сен», мугалимге «сиз» деп кайрылуу.
