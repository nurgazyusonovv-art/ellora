# Ellora: билим берүү баалуулугун өнүктүрүү планы

2026-10-21. Бул сунушталган кезек; төмөнкү функциялар аткарылган деп эсептелбейт.

## Багыт

Ар бир окуучу үчүн «эмнени түшүндү, кайсы жерде кыйналды, кийинки кадамы эмне?» деген үч суроого жооп берүү.
5E сабакта кызыктыруу баштапкы ойду чогултат; изилдөө далил берет; түшүндүрүү окуучунун ой жүгүртүүсүн ачат;
колдонуу билимди жаңы кырдаалга өткөрөт; баалоо кийинки окууну пландайт. Сабакты бүтүрүү өздөштүрүүнү далилдебейт.
Учурда 5E каркасы, ЖИ долбоору/жардамчы, критерий менен пикир, жуп/топ нускамалары жана монета дүкөнү бар.
Жаңы иш буларды кайталабай кеңейтет. Production ЖИ үчүн OPENAI_API_KEY жөндөлүшү керек.

## ЖИ жардамчынын кийинки версиясы

Жоопту дароо берүүнүн ордуна окуучунун аракетине байланышкан бир суроо/кеңеш берет, андан кийин өз алдынча мисал сунуштайт.
Мугалимге жаңылыш түшүнүктү, ылайыктуу кайталоону жана критерий боюнча пикирдин долбоорун сунуштайт.
ЖИ окуучуну акыркы баалабайт. Мугалим сунушту өзгөртүп, бекитет. Текшерүү үчүн кыргыз тилиндеги эталон учурлар,
туура эмес божомол, көчүрүлгөн жооп, тема сыртындагы сурам жана көрсөтмө бурмалоо мисалдары колдонулат.
Токен чыгымы жана сурам лимити учурдагы чектөөлөрдүн ичинде көзөмөлдөнөт.

## Пилотту уюштуруу

1. Алгач P0: азыркы функцияларды чыныгы сабакта текшерүү, маселелерди оңдоо.
2. Көндүм картасы + жоопту кайра иштөө агымын бир темада чыгаруу.
3. Ошол темага аралык кайталоону кошуп, кийинки жумада жаңы мисал менен текшерүү.
4. Мугалимдердин байкоосу боюнча P2 кезегин тактоо; баарын бир учурда кошпоо.

Ийгиликти монетанын саны менен өлчөбөйбүз. Негизги далилдер: кийинки жумадагы өз алдынча жаңы тапшырма,
ката оңдолгондон кийинки түшүндүрмө жана мугалимдин кийинки сабакты пландоого кеткен убактысы.
Булардын баштапкы абалын пилотто чогултабыз; азырынча натыйжа же өсүш тууралуу доомат жок.
Өз алдынча жооп менен ЖИ/мугалим жардам берген жооп өзүнчө белгиленет.

## P2.4 биринчи кадамынын абалы

`/lab` — шарт жана жыйынды цикли үчүн жалпыга ачык кадамдык машыктыргыч. Божомол → байкоо → түшүндүрүү, чек маанилерин өзгөртүү жана кагаз/жуп альтернативасы бар. Бул чектелген эки мисал; каалаган кодду визуалдаштырбайт, жооптор сакталбайт, негизги сабактын далилдерине жана баасына кошулбайт. Схема/дал келтирүү кийинки көлөмгө калат.

2026-10-22: конструктордогу `investigation.simulation` аркылуу модель изилдөөнүн ичинде да жеткиликтүү. Алгачкы божомолдон кийин ачылат; байкоо жана жыйынтык блоктун мурдагы жооп сактоо агымын колдонот. Моделдин басылган кадамдары өздөштүрүүнүн далили катары эсептелбейт. Чыныгы класста жаңы жөндөөнүн сакталуусун жана жоопту кайра ачууну пилоттоо али керек.

## P2.3 биринчи версиясынын абалы (2026-10-22)

Код жана 0014 миграциясы даяр: мугалим 2–6 мүчөлүү топ түзөт, ролдорду/жазуучуну айлантат; жалпы жооп версия менен сакталат, бекитилгенден кийин ар ким жеке түшүндүрмө берет. Жеке жооп топтошторго көрсөтүлбөйт. Негизги баа/прогресс/монетага таасир этпейт. Бир учурдагы редактор жок, жаңыртуу кол менен. 246 тест, lint/build, таза локалдык база жана UI текшерүүлөрү өттү. 0014 Safari SQL Editor аркылуу ellora базасына колдонулду; production build жана HTTP текшерүүлөр өттү (`ellora-5qzdoutcx`). Чыныгы аккаунттар менен толук агым жана класс пилоту али текшериле элек.
