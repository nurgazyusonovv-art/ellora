# Монета жана дүкөн — биринчи версия

Монета билимдин баасы эмес. XP, рейтинг, тест упайы жана мугалимдин баалоосу өзүнчө калат.

## Сыйлык

Бөлүктү бүтүргөндө: Кызыктыруу 5, Изилдөө 15, Түшүндүрүү 10, Колдонуу 15, Баалоо 10 монета. Бир сабактан 55ке чейин. Изилдөөнүн божомолу туура/туура эмес деп бааланбайт, бирок байкоо менен жыйынтык толукталышы керек. Эски сабактарда ошол беш бөлүктүн тартиби колдонулат.

Сыйлык `student_id + lesson_id + stage` боюнча бир гана жолу берилет. Ошол сабак башка класска дайындалса же жооп кайра жиберилсе, кошумча монета берилбейт. Жаңы өзүнчө сабактын id’си жаңы сабак болуп эсептелет. Буга чейин бүткөн бөлүктөр миграцияда бир жолу эсептелет.

`coin_wallets.balance` — коротууга боло турган монета; `earned_total` — жалпы тапкан монета. Деңгээл ар 100 тапкан монетада өсөт; сатып алууда түшпөйт. Мугалимдин кошумча 5 монеталык сыйлыгы кийинки версияга калтырылды.

## Дүкөн

`/student/shop`: эки аватар, эки алкак, эки аталыш. Баа `shop_items` таблицасынан гана алынат. Сатып алган соң буюмду профилге тандоо керек. Кадимки көрүнүшкө кайтуу акысыз, буюм сенде калат. Буюмдарды кайра сатуу же монетаны чыныгы акчага айлантуу жок.

## База жана коопсуздук

Миграция: `supabase/migrations/0010_coin_shop.sql`.

- Кадимки окуучу клиенти капчыгын, тарыхын, буюмдарын жана тандоолорун гана окуйт. Каталог бардык кирген колдонуучуларга көрүнөт.
- Түз INSERT/UPDATE/DELETE укугу жок. Баа, монета жана окуучу id’си формадан кабыл алынбайт.
- `buy_shop_item` капчык сабын FOR UPDATE менен кулпулап, балансты, инвентарды жана тарыхты бир бүтүмдө жаңыртат.
- `equip_shop_item` учурдагы окуучунун менчигин жана буюмдун түрүн текшерет.
- Монета `attempts` прогресси жаңырганда триггер аркылуу берилет. Окуучу прогрессти түз өзгөртө албайт (0003).
- Сабак/дайындама өчсө да сыйлык тарыхы жана монета калат. Аккаунт өчүрүлсө жеке капчык да өчөт.
- Монета бүтүмү ишке ашпай калса, бөлүктүн прогрессин жаңыртуу да артка кайтарылат. Жооп кайра жөнөтүлсө сыйлык бир гана жолу эсептелет.

## Текшерүү

`npm run lint && npm test && npm run build`.

Өзүнчө **локалдык тест базасында**, бардык миграциялардан кийин:

```sh
psql -v ON_ERROR_STOP=1 -f supabase/tests/coin_shop.sql
python3 scripts/test-coins-concurrency.py /path/to/psql /private/tmp 55441
```

SQL тест: жарым жооп сыйлык албайт, бөлүктөрдүн суммасы, кайталоо, башка дайындама, RLS, жетишсиз баланс, сатып алуу, тандоо, тарых. Конкуренттүү тест: эки башка буюмду же бир буюмду бир учурда алуу. Бул тесттерди чыныгы колдонуучулардын базасында иштетпеңиз.

Кол менен: окуучу бөлүктү бүтүрөт → сыйлык/капчык жаңыланат → дүкөндөн буюм сатып алат → профилге тандайт → баракты жаңыртып сакталганын көрөт. Эки өтмөктөн сатып алуу да текшерилет.
