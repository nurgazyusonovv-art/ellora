## Түстөр

Токендер `src/app/globals.css` ичинде `@theme` блогунда. Tailwind'де `bg-accent`, `text-muted` деп колдонулат.

| --- | --- | --- |
| `bg` | `#EEEBFB` | Беттин фону |
| `surface` | `#FFFFFF` | Карточкалар |
| `surface-2` | `#F4F2FB` | Прогресс тилкесинин фону, нейтралдуу чип |
| `ink` | `#292739` | Негизги текст |
| `muted` | `#747187` | Кошумча текст |
| `line` | `#E5E1F1` | Чек аралар |
| `accent` | `#5D54AF` | Негизги баскычтар, шилтемелер, прогресс |
| `accent-soft` | `#EEEBFB` | Тандалган абал, маалымат блоктору |
| `amber` / `amber-soft` | `#7A5405` / `#FBEFD2` | XP, «көңүл буруу» |

Статус түстөрү (good/amber/bad) негизги accent'тен бөлөк — алар абалды гана билдирет.

## Логотип

Белги — «e» тамгасы жана терилип жаткан сары курсор (**el**lora + код жазуу). Компонент: `LogoMark` / `Logo`
(`src/components/ui.tsx`). Ак фондо — `accent` плитка жана ак «e»; караңгы фондо (`dark`) — `#3dc3a5` плитка жана
кара «e». Курсор ар дайым `code-str` (`#F3C66E`). Favicon — `src/app/icon.svg`, PWA иконкалары — `public/icons/`.
Логотипти өзгөртсөңүз, үчөөнү тең жаңыртып, `public/sw.js`теги `VERSION`ду көтөрүңүз.

## Шрифттер

| Роль | Шрифт | Колдонуу |
| --- | --- | --- |
| Display | Inter 500/700 | Беттин аталыштары, чоң сандар (`font-display`) |
| Body | Inter 400/500/600 | Бардык текст (кыргыз тамгалары ң, ө, ү толук бар) |
| Mono | JetBrains Mono | Код, класс коддору, XP, сандар колонкада (`font-mono`) |

Inter бирдиктүү интерфейс шрифти: кыргыз алфавитинин 36 тамгасынын чоң/кичине түрлөрү (анын ичинде Ңң, Өө, Үү) шрифттин `cmap` таблицасынан текшерилди. Толук variable файл `public/fonts/Inter-Variable.ttf` ичинде; `next/font/local` аркылуу жүктөлөт, Google Fonts тармагына көз каранды эмес. Лицензиясы: `public/fonts/Inter-OFL.txt` (SIL OFL).

Өлчөмдөр: аталыш 24–30px, бөлүм аталышы 18px, текст 15–16px, кошумча 13–14px, uppercase белги 12px + `tracking`.

## Стиль: Supabase'ке окшош (2026-ноябрь)

Түстөр өзгөргөн жок — стиль гана: тыгыз, так, жука чек аралар, кичине радиустар, көлөкө дээрлик жок.

- **Радиустар** `@theme` ичинде кайра аныкталган: `rounded-md` 6px (баскыч, талаа), `rounded-lg`/`rounded-xl` 8px
  (карточка), `rounded-2xl` 8px, `rounded-3xl` 10px. Эски `rounded-[28px]` сыяктуу маанилерди колдонбо.
- **Чек аралар:** `line` — кадимки, `line-strong` (`#D6D1E8`) — баскыч жана талаалардын чети.
- **Көлөкө:** `shadow-xs` гана (баскыч, талаа, кирүү карточкасы).
- **Аталыштар:** салмагы 500–600, `letter-spacing: -0.015em`; `font-bold` аталыштарда автоматтык 600 болот.
  Беттин аталышы (`PageTitle`) — `ink` түстө, астында жука сызык.
- **Белгилер (eyebrow):** `font-mono`, 11px, uppercase.
- **Каптал меню:** ак фон, оң жагында `line` чек ара, 36px бийиктиктеги пункттар; тандалганы `accent-soft` фондо.
  Негизги аймак `surface-2` фондо. Телефондо үстүңкү тилке да ак, чек арасы менен.
- **Торчо фон** (`.grid-bg`) — башкы бет жана кирүү беттеринин жогору жагында гана.

## Компоненттер (`src/components/ui.tsx`)

- `Button` / `ButtonLink` — `primary` (accent, `accent-dark` чек ара), `secondary` (ак, `line-strong` чек ара), `ghost`.
  Компьютерде 36px, телефондо 44px.
- `Card` — ак фон, 1px `line` чек ара, 8px радиус
- `Chip` — абал белгиси, жука чек арасы менен: `good`, `warn`, `bad`, `accent`, `neutral`
- `Field` — label + input (6px радиус, фокуста accent чек ара + шакек), ката үчүн `FormError`
- `Progress` — 6px бийиктиктеги тилке
- `RichText` — `**калың**` жана `` `код` `` колдоо

## Принциптер

- **Телефон биринчи:** окуучунун бардык беттери 375px'те текшерилет. Мугалимдин беттери компьютер үчүн, бирок
  телефондо да бузулбасын (капталдагы меню → астыңкы тилке).
- Баскычтардын бийиктиги ≥44px, фокус абалы көрүнүп турсун (`:focus-visible` accent түстө).
- Абалды түс менен гана эмес, текст менен да көрсөт (чиптин ичинде сөз бар).
- Эмодзи колдонбо; иконкалар — сызык SVG (stroke 2).
- Карточкаларга чоң көлөкө жана градиент кошпо. Сабак карточкаларынын радиусу 8px; фон түстөрү кезектешет: `accent-soft`, `lilac-soft`, `rose-soft`.
- Мугалим панели: ак каптал меню (Supabase стили), `surface-2` негизги аймак; 1440px жана кеңири экранда оң жакта календарь жана чыныгы класстардын тизмеси. Телефондо бир колонка.
- Кошумча токендер: `lilac` / `lilac-soft` — `#9256BC` / `#F5EBFA`; `rose` / `rose-soft` — `#BF527D` / `#FBEEF3`; `nav-muted` — `#DEDAF7`.
- Тексттер жөнөкөй кыргыз тилинде, окуучуга «сен», мугалимге «сиз» деп кайрылуу.

## Телефон үчүн жалпы эрежелер

1023px жана андан кууш экранда жазуу талаалары кеминде 16px, баскыч/summary жана текст талаалары кеминде 44px. Масштабдоого тыюу салынбайт. Viewport коопсуз четтерди жана клавиатурада мазмундун кичирейишин колдойт. Мугалимдин үстүңкү тилкеси 68px + жогорку коопсуз чет; сабактын sticky бөлүктөрү анын астында турат. Төмөнкү меню үчүн teacher-main кошумча орун калтырат.

Карточкалар/код min-width:0 менен чектелет. Узун таблица жана код өз контейнеринде жылат; бүт беттин горизонталдык overflow'ун жашырып катаны жашырбаңыз. Сабактын бөлүктөрү телефондо горизонталдык тилке; тандалган бөлүк view/өлчөм өзгөргөндө көрүнүктүү болуп жылат. Reduced motion эске алынат. `/lab/mobile` ошол эле компоненттердин базага жазбаган үлгүсү. Физикалык Safari/Android клавиатурасы жана чыныгы аккаунт агымы өзүнчө пилот менен текшерилет.
