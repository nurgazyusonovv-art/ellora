# OpenAI жардамчысын иштетүү

1. `supabase/migrations/0008_five_e_support.sql` миграциясын туура ellora базасына колдонуу.
2. `.env.local` ичинде `OPENAI_API_KEY` кошуу. Ачкычты чатка, Git'ке же `NEXT_PUBLIC_` өзгөрмөгө жазбаңыз.
3. `OPENAI_TUTOR_MODEL=gpt-4.1-mini` (Responses жана strict JSON schema колдогон модель).
4. Локалдык серверди кайра иштетүү. Vercel үчүн ушул сервердик өзгөрмөлөрдү кошуп кайра deploy кылуу.
5. Окуучу активдүү сабактын тапшырмасынан «AI-жардамчы» ачып өз оюн жазат. Exit бөлүгүндө AI жок.

Код: `src/app/actions/ai.ts`, `src/lib/ai-tutor.ts`. OpenAI'га учурдагы суроо, изилдөө кадамдары жана окуучунун 2–1000 белгилик ою гана берилет. Туура жооптор, мугалимдин белгилери жана профилдин маалыматы кошулбайт. `store:false` коюлат; бул провайдердин бардык журналдары толук өчөт дегенди билдирбейт. База сурамдын убактысын гана сактайт.

Ар бир окуучуга сурам аралыгы ≥10 секунд, акыркы 24 саатта ≤30 сурам. API иштебей калса да жасалган аракет лимитке кирет. Жооп 250 белгиге чейинки суроо болушу керек; код жана айрым түз жооп белгилери четке кагылат. Бул чыпка AI эч качан даяр жооп бербейт деген кепилдик эмес — пилотто кыргызча сапатын жана даяр жоопту ачпашын текшерүү керек.

Мугалим AI'нын ордун толтурбайт; акыркы баалоо критерийлери менен мугалимде. Python тапшырмасынын тесттери окуучунун браузеринде иштейт, ошондуктан маанилүү баалоодо сакталган кодду да караңыз.

## Мугалим үчүн сабак түзүү

`0009_ai_lesson_generation.sql` талап кылынат. `/teacher/lessons/new` бетинде ЖИ формасы бар. `OPENAI_LESSON_MODEL` берилбесе `gpt-4.1` колдонулат; мугалимдин кеңири кыргызча мазмуну окуучунун кыска жардамчысынан өзүнчө модель менен түзүлөт. Сервер 90 секунддук таймаут жана 6500 output token чеги менен Responses strict JSON schema колдонот.

`ai_lesson_generations` ар бир сурамды API чакыруудан мурда каттайт. Модель, кирүү параметрлери, түзүлгөн текст, токендер жана статус сакталат. Ар бир мугалим акыркы 24 саатта 10 сурам жасай алат, эки сурамдын аралыгы 30 секунд. API/валидация катасы да лимитке кирет. RLS аркылуу мугалим өз жазууларын гана окуйт; клиент түз жазып лимитти айланып өтө албайт. Сервер жазуудан мурда ролду жана ээликти кадимки клиент аркылуу текшерет.

Түзүлгөн текст `/teacher/lessons/generate/[id]` аркылуу кайра ачылат. Жооп толук эмес же туура эмес болсо, сабак жарыяланбайт жана текст тарыхта калат. Туура натыйжа жөнөкөй сабак долбоору катары сакталат, мугалим мазмунун, кодун, тесттин жоопторун жана жаш куракка ылайыктуулугун текшерет.

Чыныгы сурамдан алынган текшерүү үлгүсү: `docs/examples/ai-lesson.json`. Бул үлгү текшерилген форматты көрсөтөт; мугалим аны темага жана класска ылайык баалайт. API схемасы: https://developers.openai.com/api/docs/guides/structured-outputs?api-mode=responses ; модель: https://developers.openai.com/api/docs/models/gpt-4.1 .

## Слайд иллюстрациялары

`OPENAI_SLIDE_IMAGE_MODEL` (демейки `gpt-image-2.5-flare`) Images APIге колдонулат. Презентация тандалганда ар слайдга бирден, 5–6 кошумча акы төлөнүүчү сурам бар. Мугалимдин күнүнө 10 сабак жана 30 секунддук азыркы лимити сакталат; демек кадимки UI аркылуу эң көп 60 сүрөт сурамы/күн. Автоматтык retry жок. Images APIге аккаунттун уруксаты/балансы өзүнчө текшерилет. Локалда ачкыч жок болсо жандуу тест жүргүзүлбөйт. Ачкычты чатка же браузерге чыгарбаңыз.

Расмий параметрлер: https://developers.openai.com/api/docs/guides/image-generation#customize-image-output

Жоопту текшерүү: `OPENAI_REVIEW_MODEL` милдеттүү эмес (демейки gpt-4.1-mini), учурдагы сервердик OPENAI_API_KEY колдонулат. Responses strict JSON, store:false. Мугалим басканда гана тапшырма/рубрика/жооп берилет, профилдин аты жөнөтүлбөйт. 200 сурам/24 саат, 2 секунд аралык; ошол эле жоопко сунуш кэштен алынат. Сунушту мугалим текшерип ырастайт, жооп өзгөрсө кайра текшерүү керек. Чейректик иш учурдагы сабак түзүү лимитин колдонот.

Оюндар бөлүмүндөгү ЖИ түзүү ошол эле OPENAI_LESSON_MODEL/OPENAI_API_KEY'ди колдонот. Үч өзүнчө strict schema (matching/ordering/classification), 4–8 элемент, 3500 output token жана 60 сек timeout. reserve_lesson_generation аркылуу сабактар менен жалпы 10/24 саат жана 30 сек аралык. activityKind:game тарыхы, draft сактоо, мугалим текшергенден кийин жарыялоо. Жаңы ачкыч же миграция жок.

Жаңы ЖИ сабактары үчүн презентация милдеттүү: так 5 слайд, сүрөт кызматына 5 сурам. Формадан өчүрүүгө болбойт. Сүрөт API'си жеткиликсиз болсо слайддар темага жараша текст/иконка/схема менен сакталат жана мугалимге эскертүү берилет. КТП жана чейректик сабак түзүүдө да ушул талап колдонулат.
