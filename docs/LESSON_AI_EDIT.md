# Конструктордо ЖИ менен тандалган жерди оңдоо

Мугалим өз сабагынын конструкторунда беш бөлүктүн каалаганын тандайт. Блокту ачып «Бул тапшырманы ЖИ менен оңдоо» баскычы аркылуу ЖИ панелине өтөт. Панелде текст талаасын (суроо, текст, код, критерий, слайд, ролдор…) тандайт. Учурдагы тексттен үзүндүнү белгилесе ошол үзүндү, болбосо толук талаа оңдолот. Блок тандалбаса бөлүктүн аталышы/киришүү сөзү оңдолот.

«Кошумча тапшырма / материал түзүү» режиминде түрүн, 1–3 санын, кошулуучу жерди жана ачык жооп үчүн жеке/жуп/4 окуучулук топ формасын тандайт. Жаңы презентация Түшүндүрүүдө 5 слайд, иконка/схема менен түзүлөт. Бул оңдоо агымында Images API чакырылбайт; мурдагы сүрөттөр текстти оңдоодо сакталат. Сүрөттүн темага шайкештигин мугалим текшерет.

ЖИ сунушу адегенде өзүнчө көрсөтүлөт. «Сунушту сабакка колдонуу» гана конструктордогу мазмунду өзгөртүп, учурдагы автосактоону иштетет. Убакыт/калган бөлүктөр/блоктордун ID'лери сакталат. Жаңы блокторго жаңы кайталанбаган ID берилет. Сурам учурунда сабак кол менен өзгөрсө эски сунуш колдонулбайт. Артка кайтаруу ошол ЖИ өзгөртүүсүнөн кийин башка түзөтүү болбосо жеткиликтүү; андан кийинки түзөтүүнү басып кетпейт. Барак/бөлүк алмашса панелдин сунушу/артка кайтаруусу сакталбайт; чийки ЖИ жооп тарыхта калат.

Жарыяланган сабакта кабыл алуу окуучуларга көрүнгөн мазмундун автосактоосун иштетет. Баскычтын жанында бул айтылат. Башка өтмөктөрдүн ортосунда жалпы версия кулпусу жок: бул конструктордун мурдагы сактоо чектөөсү. Мугалим тесттин суроосу/варианты, код тести же слайд өзгөрсө калган жооп/текшерүү/сүрөт менен шайкештигин, тапшырмалар кошулса убакытты карап чыгат. ЖИ тууралыгын сунуштун форматы гана далилдебейт.

## Сервер

- `requireRole("teacher")`, кадимки RLS клиент аркылуу сабактын `author_id` ээлиги текшерилет.
- Учурдагы `reserve_lesson_generation` колдонулат: бүт сабак түзүү менен биргелешкен 30 секунд / күнүнө 10 сурам лимити. Жаңы миграция талап кылынбайт.
- Чакан операция метадайындары лимит тарыхына жазылат. Ээлик кайра текшерилгенден кийин гана admin клиент ошол сурамдын жооп/токен/абалын жазат. Сабакты сервердик ЖИ аракети түз жазбайт.
- OpenAI Responses, `store:false`, учурдагы `OPENAI_LESSON_MODEL` (демейки gpt-4.1), 90 секунд timeout. Сүрөттөрдүн base64 мазмуну, окуучунун жооптору жана аккаунт маалыматтары контекстке кошулбайт. Сабактын тексттик контексти 60 KB менен чектелет.
- Strict JSON schema + сервердик форма/диапазон/ID/блок/5E текшерүүсү. Кошумча белгисиз талаа, кайталанган/бөтөн ID кабыл алынбайт. Изилдөөгө туура жооп талап кылган тапшырма, башка бөлүккө презентация кошулбайт. Бөлүккө эң көп 40 блок.
- Жаңы Python код автоматтык серверде аткарылбайт; окуучунун мурдагы Pyodide чөйрөсү колдонулат.

Расмий API форматы: [OpenAI Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs).
